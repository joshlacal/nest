# Circle AppView Spaces protocol — November 12, 2026

The AppView targets atproto revision `d4def6e9f521896ed8222f576d54923d00b5fbeb`. This exact value is served as `protocolRevision`; Catbird and Nest must compare it without abbreviation.

## Credential and notification registration

The AppView obtains a delegation token from a member's PDS and calls `com.atproto.space.authorizeSpaceSync` on the authority's space host. The body carries `credentialKey`, client attestation, and notification registration `{ endpoint, token }`. The credential is bound to the fresh P-256 `did:key` in `cnf.kid`; every credential use signs `authorization` and `atproto-space-audience` with an RFC 9421 signature tagged `atproto-space-credential`.

`APPVIEW_BASE_URL` is the notification endpoint origin. Production values must be publicly reachable HTTPS URLs without userinfo, query, or fragment. Loopback HTTP is accepted only for local development.

The public callback routes are:

- `com.atproto.space.confirmRegistration`, which authenticates the stored per-Space token and echoes the challenge;
- `com.atproto.space.notifySpaceUpdate`, which authenticates the same token and accepts `repoWrite`, `repoRemoved`, `spaceDeleted`, and `registrationExpired` updates.

Unknown Spaces, wrong tokens, malformed updates, and unknown update types fail with non-retryable 4xx responses. A revision gap or `registrationExpired` starts catch-up from the durable Space checkpoint. `spaceDeleted` first reauthorizes; data is purged only when the host declares `SpaceDeleted` during that exchange.

Migration `20261112000001_notify_tokens.sql` replaces old lease registrations. Existing lease rows cannot supply the new host-generated confirmation token, so they are discarded; active Spaces reauthorize and register on the next sweep. Circle records and sync state are unchanged.

## Response authentication and repository transport

Each `listRepoOps`, `getLatestCommit`, and `getRepo` request sends `Accept-Signature` tagged for the required profile. The request secret is derived with RFC 9180 DHKEM(P-256, HKDF-SHA256) `Export`, and the response uses an RFC 9421 HMAC-SHA256 signature. Signature labels are not identifiers: verification selects exactly one signature by tag, checks the covered structured field and optional `keyid`, then verifies the canonical RFC 8941 value. There is no unsigned or legacy header fallback.

`getRepo` is requested and accepted only as `application/vnd.dasl.star`. STAR metadata, sorted paths, record CIDs, and the commit's LtHash digest are validated before projection.

`listRepoOps` requires a MAC-authenticated commit on every page. Pages are consumed through the first response without a cursor—even when that terminal page is empty—and only that page's commit digest is compared with the accumulated record set. `RepoNotFound` is an empty repository only when no local repository state or authority head exists.

## Writer catch-up and access reads

`com.atproto.space.listWriters` returns ordered `repoWrite` and `repoRemoved` updates. A write is projected only after its revision and digest match the repository's authenticated terminal commit. A removal deletes that writer's local projections and sync state while preserving the Circle and other writers. Failed updates do not advance the Space checkpoint, so suspension and transient upstream failures preserve data for retry. `RepoTakendown` and `RepoDeactivated` are suspension signals, not deletion.

`getSpace` binds the returned `space` to the requested Space. `com.atproto.memberspace.listMembers` consumes `com.atproto.memberspace.defs#member` values and treats `NotAuthorized` as denial. Pagination is bounded and fails closed on malformed, oversized, or repeated cursors.

## Deployment cutover

1. Deploy the database migration before or with this binary.
2. Set `APPVIEW_BASE_URL` to the public HTTPS AppView origin and ensure both callback routes are reachable by space hosts.
3. Deploy Nest and Catbird with the same full protocol revision.
4. Allow the normal revision sweep to reauthorize active Spaces and repopulate notification registrations.

No repository or Circle payload rewrite is required. Old procedure names, legacy MAC headers, lease registration, and signed-commit CAR framing are unsupported after this cutover.
